# StockLab

Dashboard responsivo de administración de inventario desarrollado con
Bootstrap 5, Sass y JavaScript.

## Tecnologías

- HTML5
- CSS3
- Bootstrap 5
- Sass
- JavaScript ES Modules
- Vite
- Stylelint

## Instalación

Clonar el repositorio e instalar las dependencias:

```bash
npm install
```

## Comandos

Desarrollo:

```bash
npm run dev
```

Validación de estilos:

```bash
npm run lint:css
```

Compilación:

```bash
npm run build
```

Vista previa:

```bash
npm run preview
```

## Funcionalidades

- Dashboard de inventario.
- Indicadores KPI.
- Tabla de productos.
- Registro de productos.
- Validación de formularios.
- Detección de SKU duplicados.
- Notificaciones Toast.
- Búsqueda dinámica.
- Sidebar compacto.
- Menú móvil.
- Tema claro, oscuro y alto contraste.
- Diseño responsivo.
